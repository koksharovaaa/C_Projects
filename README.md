# C_Projects

Кластер проектов для изучения основ прикладного программирования на языке С.

## Cat, Grep
Учебный проект на C11, обственные реализации утилит cat и grep с поддержкой основных флагов, включая GNU-версии. Работа с файловым вводом/выводом, парсинг аргументов командной строки, регулярные выражения (regex/pcre2).

Стек: C11, gcc, regex / pcre2, bash (тесты), Makefile

## String.h
Собственная реализация библиотеки s21_string.h, статической библиотеки s21_string.a. Реализованы основные функции работы со строками и памятью. Unit-тесты написаны на check с покрытием >80% и сравнивают работу s21_string.h со стандартной библиотекой.

Стек: C11, gcc, check и gcov (unit-тесты), Makefile

## Decimal.h
Реализация библиотеки s21_decimal для работы с десятичными числами через 96-битный формат. Арифметические операции, сравнение, конвертация из/в int и float, округление.

Стек: C11, gcc, check и gcov (unit-тесты), Makefile

## Matrix.h
Реализация библиотеки s21_matrix для работы с матрицами. Реализованы создание, удаление, сравнение, сложение, вычитание, умножение, умножение на число, транспонирование, определитель, алгебраические дополнения, обратная матрица. Точность — 6 знаков после запятой.

Стек: C11, gcc, check и gcov (unit-тесты), Makefile

## BrickGame Tetris
Консольная игра Tetris на C11. Библиотека игровой логики на конечном автомате, терминальный интерфейс на ncurses, сборка через Makefile, покрытие unit-тестами через check (>80%). Реализованы все игровые механики: вращение, перемещение, ускоренное падение, счёт, рекорды, уровни. 

Стек: C11, gcc, ncurses, check и gcov (unit-тесты), Makefile, Doxyfile
